# 9. minSdk 31 (Android 12)

Status: Accepted

## Context

Before Android 12, BLE scanning requires the location permission (and location services on). Android 12 added
`BLUETOOTH_SCAN` (which can declare `neverForLocation`) and `BLUETOOTH_CONNECT`. The app is personal and runs on a
current phone.

## Decision

minSdk 31, targetSdk and compileSdk 37.

## Consequences

- The permissions step asks only for nearby devices, never location.
- Dynamic color is always available ([ADR 0005](0005-compose-material3-dynamic-color.md)).
- Phones on Android 11 or older cannot install the app.
